## 3. СТАНДАРТ PDC-ТЕГОВ ДЛЯ ВСЕХ МАТЕРИАЛОВ

Каждый сгенерированный предмет Artifex содержит следующие теги:
- `artifex:id` (String): уникальный идентификатор из каталога (например, `artifex:ember_ingot`).
- `artifex:type` (String): `MATERIAL` / `ORE` / `INGOT` / `GEM` / `CORE`.
- `artifex:rarity` (String): `COMMON` / `UNCOMMON` / `RARE` / `EPIC` / `LEGENDARY` / `MYTHIC`.
- `artifex:custom_model_data` (Integer): соответствующий номер CMD (2001..2150).
- `artifex:branch` (String): принадлежность к ветви (`EMBER`, `FROST`, `STORM`, `VOID`, `ANCIENT`, `CRYSTAL`, `VERDANT`, `ALCHEMY`, `BOSS`).
