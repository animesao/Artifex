# Разработка модулей

Это руководство описывает динамические модули, загружаемые `ModuleManager` Artifex. Для классов кастомных предметов см. [JAVA_API_RU.md](JAVA_API_RU.md).

## Гарантии жизненного цикла

Artifex завершает инициализацию базы данных до загрузки модулей:

1. `DatabaseManager` создаётся и подключается.
2. Готовность соединения проверяется через `isConnected()`.
3. Модули обнаруживаются и загружаются.
4. Выполняются `onEnable` модулей.

В `onEnable` `Main.getInstance().getDatabaseManager()` уже доступен и подключён. Не вызывайте `connect()` сами и не открывайте отдельный файл SQLite. Используйте общий менеджер для таблиц, запросов и транзакций.

## Правила модулей

- Держите бизнес-логику на Java; YAML/JSON используйте для настроек, описаний контента и шаблонов.
- Регистрируйте слушатели через экземпляр плагина и снимайте регистрацию в `onDisable`.
- Проверяйте необязательные зависимости: модуль не должен предполагать, что другой модуль включён.
- Для медленных запросов используйте асинхронные методы базы данных.
- Не дублируйте логику инициализации схемы `DatabaseManager`.

## База недоступна

Если базу не удаётся инициализировать, Artifex сообщает явное состояние недоступности вместо передачи полуинициализированного менеджера модулям. Модули должны обрабатывать неудачный запрос или недоступный менеджер без исключений при включении/отключении.

## Перезагрузка

`/artifex reload` перекомпилирует и перезагружает модули. Корректно снимайте состояние и регистрацию слушателей, чтобы перезагрузки не оставляли задачи и не дублировали регистрации.
