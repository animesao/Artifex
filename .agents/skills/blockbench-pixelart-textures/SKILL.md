# Blockbench Pixel Art Texture Creation Skill

Руководство и инструменты по созданию детализированных пиксель-арт текстур для 3D-моделей Blockbench и ресурс-паков Minecraft.

---

## 1. Сетка и зонирование атласа ($64 \times 64$)

Для аккуратной развёртки 3D-модели текстурный лист делится на **логические зоны материалов**:

```
+------------------------+------------------------+
|  [0..31, 0..31]        |  [32..63, 0..31]       |
|  ОСНОВНОЕ ЛЕЗВИЕ       |  РУКОЯТЬ И ОБМОТКА     |
|  - Металлическая сталь |  - Тёмная кожа/дерево  |
|  - Режущая кромка      |  - Кольца и заклёпки   |
|  - Рунные гравировки   |  - Противовес (поммель)|
+------------------------+------------------------+
|  [0..31, 32..63]       |  [32..63, 32..63]      |
|  ГАРДА И ФАСОННЫЕ УЗЛЫ |  САМОЦВЕТЫ И СПЕЦФФЕКТЫ|
|  - Золотой каст/крылья |  - Граненые кристаллы  |
|  - Защитные накладки   |  - Энергетические ядра |
|  - Фаски под 45°       |  - Всполохи / магия    |
+------------------------+------------------------+
```

## 2. Цветовые палитры материалов

Каждый качественный материал строится минимум из **4-5 градаций тона** (от глубокой тени до зеркального блика) со сдвигом по цветовому кругу (*Hue-Shifting*):

* **Сталь / Железо**:
  `#1F2430` (глубокая тень) $\to$ `#3D4758` (база) $\to$ `#6B7C96` (свет) $\to$ `#A8BCD7` (блик) $\to$ `#FFFFFF` (остриё)

* **Золото / Латунь**:
  `#5C380B` (контур) $\to$ `#966013` (тень) $\to$ `#D49522` (основа) $\to$ `#F5C747` (свет) $\to$ `#FFF3A8` (блик)

* **Рубин / Инфернальный огонь**:
  `#360808` (тень) $\to$ `#731313` (база) $\to$ `#BF2424` (свет) $\to$ `#FF5C5C` (яркость) $\to$ `#FFE6E6` (грань)

* **Ледяной хрусталь / Сапфир**:
  `#0A2540` (глубина) $\to$ `#134E7A` (тень) $\to$ `#218AC7` (база) $\to$ `#5CD2FF` (свет) $\to$ `#E8FBFF` (фасетка)

* **Изумруд / Природная эссенция**:
  `#082B14` (тень) $\to$ `#115E2D` (база) $\to$ `#1FA852` (свет) $\to$ `#58F28D` (яркость) $\to$ `#E6FFF0` (сверкание)

* **Бездна / Обсидиановая сталь**:
  `#0B0814` (тьма) $\to$ `#1C132E` (тень) $\to$ `#351D5A` (база) $\to$ `#6C38B8` (фиолетовый свет) $\to$ `#C28BFF` (руна)

## 3. Правила светотени (Shading)

1. **Единый источник света**:
   * Свет почти всегда падает **сверху слева** (классический изометрический стандарт Minecraft).
   * Верхние и левые грани куба всегда светлее правых и нижних.
2. **Избегать «Pillow Shading» (эффект подушки)**:
   * Никогда не делайте обводку темным по краям с пятном света ровно по центру.
   * Тени должны падать от выступающих частей (гарда отбрасывает тень на лезвие, каст на кольцо).
3. **Hue Shifting (Сдвиг оттенка)**:
   * Тень не просто темнее, она уходит в холодный оттенок (синий/фиолетовый).
   * Свет не просто светлее, он теплеет (желтый/белый).
4. **Контрастные фаски (Specular Edges)**:
   * Добавление светлой 1-пиксельной линии на ребро металлического предмета мгновенно создаёт иллюзию идеальной заточки и 3D-объёма.

## 4. Использование скрипта генерации текстур

Скрипт `scripts/texture_generator.py` генерирует готовые атласы $64 \times 64$ пикселей с градиентами, фасками и шумом:

```bash
python scripts/texture_generator.py --type weapon --theme infernal --output infernal_sword.png
```
Поддерживаемые темы: `infernal`, `frost`, `storm`, `nature`, `void`, `holy`, `ancient_gold`.
