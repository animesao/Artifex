# Blockbench 3D Modeling Skill (Minecraft Java Edition)

Руководство и инструментарий для разработки высококачественных 3D-моделей в формате Blockbench (`.bbmodel`) и Minecraft JSON для оружия, брони, инструментов, аксессуаров и предметов.

---

## 1. Архитектура формата `.bbmodel`

Blockbench хранит проекты в формате JSON со следующей структурой:
```json
{
  "meta": {
    "format_version": "4.10",
    "model_format": "free",
    "box_uv": false
  },
  "name": "model_name",
  "geometry_name": "model_name",
  "resolution": {
    "width": 64,
    "height": 64
  },
  "elements": [
    {
      "name": "blade_segment",
      "from": [7, 8, 7],
      "to": [9, 14, 9],
      "origin": [8, 8, 8],
      "rotation": [0, 0, 22.5],
      "faces": {
        "north": { "uv": [0, 0, 8, 8], "texture": 0 },
        "east":  { "uv": [0, 0, 8, 8], "texture": 0 },
        "south": { "uv": [0, 0, 8, 8], "texture": 0 },
        "west":  { "uv": [0, 0, 8, 8], "texture": 0 },
        "up":    { "uv": [0, 0, 8, 8], "texture": 0 },
        "down":  { "uv": [0, 0, 8, 8], "texture": 0 }
      }
    }
  ],
  "textures": [
    {
      "id": "0",
      "name": "model_name.png",
      "folder": "item",
      "source": "data:image/png;base64,..."
    }
  ],
  "display": { ... }
}
```

## 2. Строгие ограничения движка Minecraft Java Edition

При экспорте в модель предмета (`assets/<namespace>/models/item/<name>.json`) движок Minecraft накладывает строгие ограничения:

1. **Вращение элементов**:
   * Разрешён поворот **только вокруг одной оси** (`x`, `y` или `z`).
   * Допустимые углы: **-45.0, -22.5, 0.0, 22.5, 45.0**.
   * Любые другие углы (например, 15°, 30°, 60°) или вращение по двум осям вызывают сбой рендера или ошибку валидации модели.
   * Формат в JSON Minecraft:
     ```json
     "rotation": {
       "origin": [8.0, 8.0, 8.0],
       "axis": "z",
       "angle": 22.5
     }
     ```

2. **Нормализация UV-координат**:
   * В Minecraft JSON координаты UV граней обязаны находиться в диапазоне **0.0 .. 16.0**.
   * Если текстура имеет размер $64 \times 64$, пиксельные координаты $(U, V)$ масштабируются формулой:
     $$U_{\text{mc}} = U_{\text{px}} \times \frac{16.0}{\text{width}}$$
     $$V_{\text{mc}} = V_{\text{px}} \times \frac{16.0}{\text{height}}$$

3. **Координатная сетка**:
   * Сетка одного стандартного блока: от `[0, 0, 0]` до `[16, 16, 16]`. Центр блока: `[8, 8, 8]`.
   * Модели предметов могут выходить за пределы сетки (допустимый диапазон `[-16, -16, -16]` .. `[32, 32, 32]`).

## 3. Техники моделирования сложных 3D-форм

### А. Изогнутые лезвия (косы, сабли, катаны)
Составляются из цепочки сегментов, где каждый следующий сегмент смещается и поворачивается на $22.5^\circ$ или $45^\circ$:
* Сегмент 1 (корень): наклон $0^\circ$
* Сегмент 2 (изгиб): наклон $22.5^\circ$ (pivot на стыке с сегментом 1)
* Сегмент 3 (кончик): наклон $45^\circ$ (pivot на стыке с сегментом 2)

### Б. Восьмигранные кольца и круглые медальоны
Создаются из **8 элементов**:
* 4 прямых куба: верх, низ, лево, право
* 4 угловых куба: повернуты на $45^\circ$ вокруг оси `Z` (или `Y` для горизонтальных колец) и срезают углы, образуя правильный круг.

### В. Кристаллы и граненые камни
* **Октаэдр / Бипирамида**: центральный куб-ядро и 4 диагональных клина под углом $45^\circ$.
* **Изумрудная огранка**: площадка (таблица), скошенные фаски и каст.

## 4. Эталонные Display Transforms (Позиционирование в руках)

Для ручного оружия (мечи, косы, копья, кинжалы):
```json
{
  "display": {
    "thirdperson_righthand": {
      "rotation": [0, -90, 55],
      "translation": [0, 4.0, 0.5],
      "scale": [0.85, 0.85, 0.85]
    },
    "thirdperson_lefthand": {
      "rotation": [0, 90, -55],
      "translation": [0, 4.0, 0.5],
      "scale": [0.85, 0.85, 0.85]
    },
    "firstperson_righthand": {
      "rotation": [0, -90, 25],
      "translation": [1.13, 3.2, 1.13],
      "scale": [0.68, 0.68, 0.68]
    },
    "firstperson_lefthand": {
      "rotation": [0, 90, -25],
      "translation": [1.13, 3.2, 1.13],
      "scale": [0.68, 0.68, 0.68]
    },
    "gui": {
      "rotation": [0, 0, -45],
      "translation": [0, 0, 0],
      "scale": [0.7, 0.7, 0.7]
    },
    "ground": {
      "rotation": [0, 0, 0],
      "translation": [0, 2, 0],
      "scale": [0.5, 0.5, 0.5]
    },
    "fixed": {
      "rotation": [0, 180, 0],
      "translation": [0, 0, 0],
      "scale": [0.8, 0.8, 0.8]
    }
  }
}
```

## 5. Запуск Blockbench

Установленная на системе версия Blockbench:
`C:\Users\Anime\AppData\Local\Programs\Blockbench\Blockbench.exe`

Для открытия любой модели:
```powershell
Start-Process "C:\Users\Anime\AppData\Local\Programs\Blockbench\Blockbench.exe" -ArgumentList "path\to\model.bbmodel"
```
